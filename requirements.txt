# InfractiVision — Dependencias
# Compatible con Windows / Linux / macOS. Probado con Python 3.10–3.11.

# Instalar torch con soporte CUDA desde el índice de PyTorch:
#   pip install -r requirements.txt
# (el índice extra se define abajo). Sin él, pip baja el wheel CPU-only de PyPI
# y la app nunca usa la GPU.
#
# Notas multiplataforma:
#   - Tkinter viene incluido con el instalador de Python en Windows y macOS.
#     En Linux instálalo via gestor del sistema:
#         Debian/Ubuntu:  sudo apt install python3-tk
#         Fedora:         sudo dnf install python3-tkinter
#         Arch:           sudo pacman -S tk
#   - Audio (beeps): se usa `winsound` solo en Windows; en Linux se intenta
#     `paplay`/`aplay` y en macOS `afplay`. No se requiere paquete extra.
#   - Iconos de ventana: `.ico` en Windows, `.png` en Linux/macOS — el helper
#     `src.core.utils.icon.set_window_icon` lo gestiona.
