# InfractiVision — Dependencias
# Stack compatible Windows / Linux / macOS. Python 3.10 (Windows y Linux) o 3.11.
#
# ⚠️  CONFLICTO CRÍTICO DE VERSIONES (no cambiar sin testear):
#   torch 1.13.1 fue compilado contra NumPy 1.x → exige numpy<2.
#   opencv-python >=5.0.0.93 exige numpy>=2 (en Python >=3.9).
#   Por eso numpy se fija en 1.26.4 y opencv en 4.9.0.80.
#   NO subir numpy a 2.x ni opencv a 5.x: rompe la inferencia (YOLO/OCR)
#   con "RuntimeError: Numpy is not available".
#
# Instalar con soporte CUDA 11.7 (GPU NVIDIA, driver >= 450, GTX 1650 Ti OK):
#   pip install -r requirements.txt
# El índice extra resuelve torch/torchvision +cu117. Sin él, pip baja el
# wheel CPU-only de PyPI y la app nunca usa la GPU.
#
# Notas multiplataforma:
#   - Tkinter viene incluido con el instalador de Python en Windows y macOS.
#     En Linux instálalo vía gestor del sistema:
#         Debian/Ubuntu:  sudo apt install python3-tk
#         Fedora:         sudo dnf install python3-tkinter
#         Arch:           sudo pacman -S tk
#   - Audio (beeps): `winsound` en Windows; en Linux `paplay`/`aplay`;
#     en macOS `afplay`. No requiere paquete extra.
#   - Iconos: `.ico` en Windows, `.png` en Linux/macOS (lo gestiona
#     `src.core.utils.icon.set_window_icon`).
#
# Quién usa qué (imports reales del código):
#   - core (src/core): numpy, opencv-python, torch, ultralytics, pillow,
#     psutil, matplotlib (reporte de auto_rectifier).
#   - gui/preprocessing_dialog: scipy, scikit-learn, scikit-image, pandas.
#   - infraestructura: requests, deep-sort-realtime, google-cloud, firebase.
#   - opcionales (NO en este archivo): easyocr/paddleocr (requirements-ocr.txt),
#     mysql (instalar mysql-connector-python>=8.0 si se activa el repo MySQL).
