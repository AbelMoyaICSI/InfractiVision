## 🎯 Guía para Capturas

### 📋 **Estándares de Capturas**

- **Resolución**: Mínimo 1920x1080
- **Formato**: PNG con transparencia si es necesario
- **Compresión**: Optimizada para web (< 500KB por imagen)
- **Contenido**: Interfaz limpia, sin datos sensibles

### 🖼️ **Tipos de Imágenes Necesarias**

1. **Pantalla Principal**: Welcome screen con logo y navegación
2. **Módulo Foto Rojo**: Video cargado, detecciones activas
3. **Panel de Placas**: Lista de placas detectadas con timestamps
4. **Gestión de Infracciones**: Tabla con registros y filtros
5. **Configuración**: Ventanas de ajustes y parámetros
6. **Evidencias**: Ejemplos de capturas de vehículos y placas

### 🎨 **Consejos para Mejores Capturas**

- Usar datos de ejemplo realistas pero ficticios
- Mostrar el sistema en acción con detecciones
- Incluir elementos de UI importantes (botones, menús)
- Evitar información personal o sensible
- Usar buena iluminación y resolución

## 📝 Notas

- Las imágenes se actualizarán conforme evolucione la interfaz
- Mantener consistencia visual entre capturas
- Considerar capturas en modo día/noche para mostrar capacidades

*Para agregar nuevas imágenes, simplemente colócalas en esta carpeta y actualiza la referencia en README.md*
